# GoCorona

Адаптивная вёрстка лендинга по макету из Figma.

[Открыть сайт](https://Az212At.github.io/go-corona/)

Дизайн-макет: [Figma](https://www.figma.com/design/XK8tit8FDz4f79AuMXI3rS/Gocorna-Website?node-id=0-1)

## Технологии
HTML, SCSS (БЭМ, партиалы), адаптив, JavaScript для анимации появления блоков

## Запуск
npm install
npm run sass
npm run build

## О проекте
Макет: Figma Community. Вёрстка и код мои.
